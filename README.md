Financial Analysis Chatbot

A rule-based Python chatbot that answers questions about Microsoft, Apple, and Tesla using their 2025 vs 2024 financial data.

Background

Built as part of a Forage job simulation: BCG X, GEN AI. The task was to develop an AI chatbot that can analyze financial data and provide insights, integrate the previously extracted and analyzed data into the chatbot system and test the chatbot to ensure it can effectively communicate financial performance insights and comparisons.

What it does
Reports total revenue and net income for each company, with year-over-year growth
Compares the three companies on revenue, profitability, and cash flow
Names the best and worst performer
Gives an investment view for each company
How to run
Install Python 3 and pandas (pip install pandas)
Run: python financial_chatbot.py
Type a question, such as “compare revenue” or “net income Tesla”. Type quit to exit.
